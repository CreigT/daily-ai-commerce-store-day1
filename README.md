# Daily AI Commerce Store - Day 1
**Simple Configurable Storefront Landing Page**

Production-ready HTML store.  
**The only thing you need to do is edit `config.js` and push.**

## Quick Start (3 minutes)

1. Edit `config.js` with your product details and payment link (Stripe Payment Link, Gumroad, LemonSqueezy, etc.)
2. Commit & push to this repo
3. On Vercel: Import this GitHub repository → Deploy
4. Done. Store is live.

### Variables you control
- Product name, tagline, price
- Description and feature list
- Payment link (the paywall)
- Images (use any public URL)
- Testimonials

Everything else is already built and optimized.

## Deploy to Vercel
- Go to [vercel.com/new](https://vercel.com/new)
- Select this repository
- Click Deploy
- (Optional) Add custom domain

## Local Preview
Open `index.html` in any browser.
